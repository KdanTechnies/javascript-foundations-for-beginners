# JavaScript Foundations for Beginners

A beginner friendly JavaScript project designed to teach students the core concepts of programming through practical examples and exercises.

## Topics Covered

- Variables (`let` and `const`)
- Updating Variables
- Data Types
- Console Logging
- Basic JavaScript Syntax

## Learning Objective

By the end of this project, students should be able to:

- Store data in variables
- Understand the difference between `let` and `const`
- Work with strings, numbers, booleans, and undefined values
- Use `console.log()`
- Read and understand simple JavaScript errors
